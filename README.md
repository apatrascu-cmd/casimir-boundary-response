# Boundary-response closure and controlled intermittency tests for Casimir-pressure fluctuations

Andrei Tudor Pătrașcu · FAST Foundation, Destin, FL 32541, USA

[Read the paper](manuscript.pdf) · [Reproduction files, part 1](reproducibility-part1.zip) · [part 2](reproducibility-part2.zip)

Author manuscript submitted to Annals of Physics on 7 October 2026. Not an accepted or publisher-formatted article.

## What this repository contains

Ordered pressure statistics, independent controls, and frozen numerical evidence. The reported hierarchy does not show a persistent anomalous exponent. The frozen TeX inside reproducibility/paper is required by the claim-to-data verifier; it is not a second public PDF.

`manuscript.pdf` is the single current reading copy. After extracting both reproduction archives into the same directory, `reproducibility/` contains the final scripts, required inputs, archived outputs and controls used by the paper. Source files needed to compile the paper are included where available.

The frozen computational package is archived at [doi:10.5281/zenodo.23215768](https://doi.org/10.5281/zenodo.23215768).

## Reproducing the results

Download [part 1](reproducibility-part1.zip) and [part 2](reproducibility-part2.zip), and extract both into the same directory, preserving their folders. The two ZIP files contain different files; both are needed for the complete record. Start with the README inside the extracted `reproducibility/` directory. [Verification record](REPRODUCIBILITY.md). They distinguish quick controls and reconstruction from the longer numerical campaigns. Keep the archived outputs intact and run experiments in a separate working copy. The complete package can be downloaded using GitHub's Code → Download ZIP.

This release excludes abandoned experiments, superseded drafts, private correspondence and internal working notes. Reported negative results and controls remain part of the scientific evidence.
